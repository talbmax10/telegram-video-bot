# بوت تحميل الفيديو — تيك توك / إنستغرام / يوتيوب

بوت تليجرام يحمّل فيديوهات تيك توك وإنستغرام ويوتيوب ويرسلها لك داخل تليجرام.
يجرّب جودة 720p أولاً، وإذا كان الملف أكبر من 50 ميغا (حد تليجرام) ينزل لـ 480p ثم 360p.

## التشغيل على Render (الطريقة الصحيحة)

1. ارفع هذا المستودع على حسابك في GitHub (الكود جاهز، ما يحتاج تعديل).
2. افتح [render.com](https://render.com) وسجّل دخول.
3. اضغط **New +** ← **Background Worker**.
4. اختر هذا المستودع `telegram-video-bot`.
5. Render راح يكتشف `render.yaml` ويستخدم Docker تلقائياً.
6. في **Environment Variables** أضف:
   - Key: `TELEGRAM_BOT_TOKEN`
   - Value: التوكن الحقيقي للبوت من @BotFather
   - ⚠️ **لا تكتب التوكن أبداً في أي ملف أو في GitHub** — بس في إعدادات Render.
7. اضغط **Create Background Worker** وانتظر اكتمال البناء.
8. افتح البوت في تليجرام (@booty11bot) ودز `/start` ثم جرّب رابط فيديو.

## ملاحظة مهمة عن خطة Render

- **Background Worker ما يشتغل على الخطة المجانية** — يحتاج خطة Starter بحوالي **7 دولار/شهر**، وهي الخطة الصحيحة للبوت اللي يشتغل 24 ساعة بدون توقف.
- الخطة المجانية فيها Web Service فقط، وهي تنام بعد 15 دقيقة بدون زيارات، فالبوت راح يتوقف وما يصحى لوحده (لأنه ما يستقبل زيارات ويب). لذلك لا تستخدم الخطة المجانية لهذا البوت إلا إذا قبلت بهذا التوقف.
- الكود فيه خادم صحة صغير على `$PORT` (يشتغل فقط إذا كان المتغير موجوداً)، حتى يشتغل أيضاً كـ Web Service إذا اخترت ذلك.

## التشغيل محلياً

```bash
pip install -r requirements.txt
TELEGRAM_BOT_TOKEN=... python bot.py
```

يحتاج `ffmpeg` على الجهاز (لدمج الصوت والفيديو في يوتيوب).

## الملفات

| الملف | شنو هو |
|---|---|
| `bot.py` | كود البوت كامل |
| `requirements.txt` | المكتبات: python-telegram-bot, yt-dlp |
| `Dockerfile` | صورة Docker مع ffmpeg |
| `render.yaml` | تعريف خدمة Render (Background Worker) |
